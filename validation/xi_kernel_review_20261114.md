# ξ kernel pilot 的审查与验证

工作解释来自用户确认的 sum_i Zi K(r-ri)。原输入不再仅是 rho，冻结的局部环境矩先沉积为多通道 ξ，
训练只用其平面低频投影作最小原理试验；3D 核另外做质量/周期/旋转与平移检查。

已核验：

- 同一组 O 位置，仅改变 H 朝向，密度不变而所选环境通道改变。
- 粒子数通道守恒；等价粒子重排/周期像不引入额外差异。
- 标量凸网络梯度、Hessian 与有限差分一致，参数梯度可穿过 Hessian。
- 核的第一谐波衰减 lambda 进入场的共轭系数，不能漏除 lambda。
- 全白化会混合密度和环境，密度响应使用 P S H^-1 S^T P^T/lambda²；
  Gaussian 倾斜和 Schur 补解析检查通过，不能直接拿 H^-1 左上角。
- 外势对数权重与已知微观势完全一致，白化后的梯度标签符号/尺度一致。
- 训练、验证、最终测试的时间段有缓冲，最终测试统计在 checkpoint 选定后计算。
- 源/目标均值和协方差做配对新增误差检查；时间尺度包括两者的影响量。
  若拟合数据不足以容纳合适时间块，保留为明确标记的经验测试，strict qualification 不伪称通过。
- 未收敛驻定解保留残差并从预测误差平均中分离；描述符重编码读取原 feature_basis。
- 两个模型分别报告参数量；未训练二次参考也报告，避免把白化嵌入的源协方差误称为学习增益。

范围：Γ 是固定 N、T 的有限维 Legendre 总有效自由能，不是已验证的连续 Fex。
普通 c1/c2 标签没有被重命名为 ξ 导数。精确环境极小化后密度响应应与精确仅密度模型一致；
此试验不证明密度在原则上不充分。有限核矩不保证完整保留高阶信息。
归属切换可能使原子坐标上的描述符不连续；没有声称原子力可微或强外势准确。
核对称性已测试，但试验网络没有结构化保证连续平移对称性；全 ξ 变分及可实现性仍未验证。
