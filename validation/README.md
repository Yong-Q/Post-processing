# 验证范围与结果

2026 年 11 月 12 日，本程序在 Python 3.10 环境下通过27项测试，涵盖：正交与restricted triclinic盒、跨周期OH重建、最短镜像对格点枚举、任意旋转和邻居置换不变量、相同H交换、周期Voronoi体积守恒、直方图及有限N配位归一化、H身份匹配的取向时间相关、反应性拓扑掩码和端到端输出。移入此独立仓库后另行复跑测试，包含本地docs中86项能力清单的读取校验。

每个样本曾对source frame 200–223执行24帧端到端运行，并通过双文件批量入口的2帧测试。默认输出176维不变特征和等变系数；实际统计范围、掩码与缺字段状态写入各自report.json。小样本运行验证执行和定义一致性，不证明全量物性收敛。

完整扫描发现原始mol分组在第162、353帧首次出现异常OH距离。`topology_event_diagnostics_20261112.json`保存前后帧的距离和力，支持原配对不再适用这一判断；不能据此单独确定化学机制或势函数的物理正确性。最近O几何归属、非H2O掩码及原子数据保留是后处理措施，不是修复原MD的证明。

真实帧中各原子独立平移整盒后，OH、距离、q和特征差异约1e-14；Voronoi体积的镜像表示相对差异低于4e-6。该精度指计算中双精度对照，HDF5大数组的float32存储另有舍入误差。稀疏存帧间的未观测运动不在这些空间几何检查的保证范围内。

力单位在原dump中未声明，默认native_unknown；温度、能量、速度、电学数据等不可由现有坐标凭空恢复。c3/c4、自由能以及板书中未定义的FEM/GEN不属于已完成实现。
