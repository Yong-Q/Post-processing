# 六物种实施计划

目标：六类分子均能在统一入口运行，并由实际轨迹验证；不替换既有水结果。

- [ ] 刷新Zenodo目录，下载六物种各一条共同密度标记轨迹，验证字节数与MD5。
- [ ] 独立实现分子定义、重原子中心、动态H归属、内部几何和对称性测试（molecules.py）。
- [ ] 独立实现通用C/H/N/O环境与中心形状耦合特征及对称性测试（molecular_features.py）。
- [ ] 主流程、通用RDF/OZ、质量/密度/温度/物种/中心定义元数据、批量CLI及能力清单。
- [ ] 对六类真实输入先端到端小样本，再全帧运行所支持的统计；不将几帧测试伪称全帧完成。
- [ ] 更新README，逐物种说明支持性质和不可适用量，保存验证摘要。
- [ ] 全套测试、独立审查、清理任务临时文件、提交并推送GitHub。

任务间只共享接口约定，分子识别与编码实现分别在独立文件中进行。所有分子间距离、成键向量、分子中心及扭角均在PBC下处理。关键取舍和未验证前提记入本设计与运行报告，不声称适用于未配置的任意混合物或化学反应网络。
