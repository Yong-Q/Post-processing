# 新板书的理解与程序对应

依据2026年11月12日讨论中的白板照片。原始照片未包含在此仓库。中间可辨认为空间与特征的组合，左侧为微观原子构型到特征表示的编码及返回箭头；右侧分出 SPE-MLIP、SPE-Statistics 和写作 rho(xi) 的 SPE-cDFT；下方有 smear、离散化、FEM、SPE-GEN 和回到场表示的求解路线。

工作理解：老师可能希望以位置和局部环境特征作为统一表示，分别服务于相互作用、特征统计、泛函以及连续场求解。若 rho(xi) 的读法正确，这可能涉及环境特征空间上的分布，而不意味着完全取消统计密度。SPE、xi、lambda 的准确含义与下方求解方程尚需老师确认，不能据板书直接推定已建立一种新自由能理论。

本次落实为：原子与分子局部环境的可追溯保存、分子取向和多体特征、不变/等变通道，以及特征边缘分布、协方差和低维联合统计。没有声称有限特征能无损重建构型，没有实现未经定义的 FMM/FEM 或生成方程，没有把统计向量分布直接当成自由能。

具体特征与接口见 ../README.md；周期边界和几何换配对由测试及真实轨迹验证记录支持，和系统级物理验证分开。
