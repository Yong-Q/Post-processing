# 小微扰静态训练数据：设计与执行记录

用户授权：拉取最新 16 位有效数字能量；先测试温度、外势允许幅度，再生成训练数据；
批量计算提交 Slurm，不监听。基线代码/能量提交 `353cb2b`，46 条 NVT 轨迹。

## 选择与用途

采用单源 NVT 构型重加权，而非重新采样；不同密度盒不直接混合成 MBAR 样本。
温度方向和空间外势方向各自扫描，再筛查联合扰动。不同目标共享原轨迹，不能当作独立 MD。
本设计由代理按用户已授权范围选择，无需新增模拟或化学势。

外势是人为定义的光滑周期性分子中心标量势，不是物理电场：
`V(X)=kBT0*a*sum_m f(s_m)`，`s=(r @ inv(cell)) mod 1`。
允许形状为沿一个晶胞分数坐标的 cos/sin，一、二谐波，以及 cos1+0.5sin2。
全部中心计入能量，包括 H 转移瞬间的固定重原子骨架中心；有效分子筛选仅用于取向/局部特征。
`log q=(beta0-beta)*(U-Uref) - (beta/beta0)*a*sum f`。

## 先测范围，再生成

1. 严格匹配 CSV、NPZ、HDF5 的 step、帧数、模型和温度标记，保留哈希。
2. 缓存逐帧 RDF、中心分箱、508 特征的分子求和/有效分子数、取向和局部标量。
   原始逐分子特征保留在来源 HDF5；权重按整帧分配。
3. 固定去除前 20% 帧，并检查能量、结构因子、局部结构的前后半段分块差异；
   此选择不是平衡已获证明。自相关决定分块尺度，块数不足则不合格。
4. 前半保留时间块用于挑选幅度，后半用于独立于幅度选择的诊断确认。
   每条温度/外势方向从小到大测试，首次失败后停止该方向；正负范围分别记录。
5. 温度/外势联合候选必须重新检查，不能把各轴上限组成矩形并直接接受。
6. 全部状态先完成范围报告，再开始标签生成；作业内顺序执行，无监控或收集作业。

## 接受规则（计算前固定）

- 使用对数权重；帧与等长时间块的 ESS 比例均 >=0.90；单帧最大质量 <=2/N。
- 对每项保存的 QoI，配对 delete-one-block jackknife 计算
  `SE(A_target-A_source) <= SE(A_source)`；同时保存目标 SE。
  这是“新增采样方差不超过原采样方差”的诊断，不是已知目标真值的偏差界。
- 基线和每类标签前后半段差异 <=4 个合并标准误；至少 8 个完整块；以两个块尺度检查误差，
  误差明显未稳定则不合格。非零结构因子和能量也参与基线检查。
- 温度/外势权重参数仅从前半段标定，后半段必须满足相同规则。
- 不用伪计数补空箱，不裁剪负谱，不正定投影，不正则化后伪装成原响应。
- 状态通过不代表所有标签通过；每类标签独立保留资格与拒绝原因。

## 标签语义

- 直接统计：来源状态的等权结果，来源标记 `direct_estimate`。
- 温度扰动：先重加权逐帧 RDF，再 OZ 得到标量中心 c2；输出径向、k 域和 PRL 平面投影。
  时间块重算整个非线性链；另存截断/窗函数敏感性。有限 N/cutoff 零模仍是未解决假设，
  不把它升级为合格的热力学 c1 密度积分标签。
- 外势扰动：密度剖面与 `ln(rho)+beta V` 的空间中心化 c1，无绝对化学势锚。
  分箱给出势的 Boltzmann 箱平均和离散化差；有坐标的表述受分箱近似限制。
- 外势 c2：另存固定 N 分箱计数的 Legendre 响应余量
  `Q.T diag(1/mean_count) Q - inv(Q.T Cov(count) Q)`。
  Q 正交于全 1 向量；这不是体相径向 OZ，也不是无限体系连续分子 c2。
  保存 6、12 箱的各自定义，不能作为相同标签直接混用。c1 另保存 6/12/24 箱近似；
  箱内势的检查不能界定箱内未知 c1 变化，因此连续空间 c1 的分辨率资格不自动通过。
- 保存局部 508 特征、几何/取向汇总的重加权均值与误差；不构造逐分子 c1/c2 假标签。
- 动力学不生成目标标签。JCTC `acs.jctc.6c01851` pp.4–5 Eq.16–30
  含 Langevin 路径转移概率和每步随机量，我们的稀疏构型不具备这些输入。

## 管理与限定

每个候选记录源轨迹 SHA256、源 HDF5、能量 SHA256、模型 SHA256、source frame/step、
权重、温度、势形状/幅度/单位、分块参数、资格与拒绝原因。
标签使用 `direct_estimate`、`reweighted_diagnostics_passed`、`reweighted_unqualified`、`invalid`。
通过仅表示采样诊断通过，没有独立目标态 MD 确认、没有证明不存在未采到的亚稳态。
现有能量元数据没有输入轨迹哈希，旧后处理报告没有生产模型哈希；同名状态、step、
T、N/V、能量模型哈希均核对，但能量与原始具体构型/生产 Hamiltonian 的关联仍依赖生产者声明。
该前提传播到全部派生标签，`strict_independently_verified_training_eligible=false`；
不能把诊断通过误读为已经独立核验构型绑定或验证了目标真值。
原始状态和所有派生目标的 `split_group` 相同，训练/验证/测试按来源轨迹或更高层分组划分。
各字段保留误差；数据量扩大不等于独立信息量扩大。
