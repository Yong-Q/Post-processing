# Zi × K 的 ξ 场：模型与小规模检验

依据老师板书照片及本次说明，当前采用的工作解释是

$$
\widehat{\boldsymbol\xi}_X(\mathbf r)
=\sum_i Z_i(X)K_h(\mathbf r-\mathbf r_i),\qquad
\boldsymbol\xi(\mathbf r)=\langle\widehat{\boldsymbol\xi}_X(\mathbf r)\rangle.
$$

每个位置配有 L 维环境向量，图像位于 R³×Rᴸ。ξ 本身在这个写法中是 R³→Rᴸ 的场，
不能同时把它误称为一个 R³+L 维坐标向量。若老师最终定义是联合分布 ρ(r,z)，本式是它的有限环境矩；
二者不完全等价，有限矩不保证保留全部高阶信息。

Z_i 是先从每帧局部环境编码的向量，不是原子序数 Z 的默认同义词。
本次冻结已有平滑形状/环境展开，选 3 个可解释通道：O 的径向环境、H 环境的 l=2 power、
中心 H 形状与邻居 H 环境的 l=1 耦合。它们不是整条轨迹的固定分子类别指纹。
使用保留的原始展开系数，因此也为 H 转移中间态构造一般局部特征，不强制赋予标准水取向。
先对每帧每个中心编码，再加权平均；不能先平均坐标再编码。

增加 Z_i,0=1 用于粒子数守恒；ρ 是 ξ 的这个投影，不再是唯一输入。
核按周期边界构造并归一化。现有完整 508 维留作后续扩展，本次 3 通道不能称为完整编码。

## 与之前模型的区别

PRL 输入仍是密度场，标量自由能的密度梯度/Hessian 对应 c1/c2。
PNAS 派生的本地 FullXiC1 仍使用 q=rho/rho_ref，xi 是追加到各网格点的条件指纹：
`rigid-env-variational-xi-20261013/model.py` 的 free/forward 仍对 q 求导。
本试验的主变量改为随位置变化的环境场，模型输出标量，再对这个场的有限投影求导。

## 先检验哪些事情

1. 周期核的归一化、平移/等价原子/全局旋转下应有的变换规则。
2. 同一组 O 中心，仅改变 H 的相对取向：ρ 不变而 ξ 环境通道改变。
3. 真实水轨迹中重建的 3 通道与原 508 维相应列一致，记录原始输入哈希。
4. 模型的梯度/Hessian 与有限差分一致，局部凸性成立。
5. 用同一轨迹、相同划分做仅密度与 ξ 的有限维响应拟合，比较共同的密度响应预测。

## 可解释的训练接口

不能直接把 δF/δξ 命名成原密度 c1，也不能把 ξ-Hessian 填进体相 OZ c2 文件。
本次定义固定 N、固定 T 的有限观测量 A(X)：ξ 的平面投影之零频环境矩及第一谐波。
常数粒子数模移除。先做平面投影与 PRL 的几何一致；实际 3D 核输入另外检验，
本次训练不冒充已经训练完整 3D 连续泛函。

$$
W(s)=\ln\langle e^{s\cdot A(X)}\rangle_0,\qquad
\Gamma(m)=\sup_s[s\cdot m-W(s)].
$$

Γ 是包括熵的受限 Legendre 有效自由能，不是已知的连续空间 Fex。
局部关系为 ∇Γ=s、HΓ=Cov(A)^{-1}，仅对非冗余、采样支持的子空间成立。
已知位置外势对应 s 的密度分量，环境分量为零；不需要伪造化学势或绝对自由能标签。
总体归一化常数和固定粒子数的规范自由度不训练。

第一谐波经过核衰减 λ=exp(-2π²σ²)。裸位置外势的共轭系数必须除以 λ；
白化 A=A0+Sx 后，梯度为 Sᵀs，共同密度响应为 Pρ S Hx⁻¹ Sᵀ Pρᵀ/λ²。
不能在白化混合环境后简单取 Hx⁻¹ 的左上角充当密度响应。
精确地对环境自由度极小化时，联合 Γ 与仅密度 Γ 必须给出一致的密度响应；
本次不同结果只说明有限模型/数据近似差别，不能证明密度本身无法决定密度响应。

输入先按训练集均值和协方差白化；近奇异方向不伪装成有数据的零特征值。
模型输出 Γθ，为正定二次项加正权 Softplus 凸网络，保持光滑和凸性；
常数/线性规范在训练参考点消除。训练损失包括已知外势下的梯度约束和
`HΓ × C - I` 的有限子空间响应约束，每个模型使用自身观测量的 C。
仅密度基线与 ξ 模型分别报告参数量，不能把不同维数的损失直接比较成模型优劣。

外势仅为第一谐波周期标量势，按权重重叠和时间分块诊断保留；不重新跑 MD。
训练/验证/测试使用预声明时间段与间隔，并按不同外势相位/幅度区分。
最终测试只在选定 checkpoint 后计算；同轨迹划分依然不能冒充独立目标态验证。
比较共同的密度傅里叶响应、驻定求解和误差，不仅比较各自的训练损失。

## 允许声称的结论

这是表示、求导和有限维响应拟合的最小原理测试。即便成功，也尚未证明 ξ 对真实 Fex 充分、
跨分子泛化、全取向分布、完整三维变分求解或强外势预测。
ξ 的通道依赖邻域，不能未经闭合就把普通 lnρ 的 Euler 方程逐字替换成 lnξ；
环境矩可实现性和理想项/投影需要另行定义。
当前 owner 依赖的 H 归属在传递时可能不连续，静态观测量可用，但不声称原子坐标上的全局光滑性。
有符号耦合通道使用 signed-log，不对负数取普通对数。

白化已经使用训练来源协方差，未训练的 Γ=|x|²/2 就能复现该来源的线性响应。
因此另外报告这个二次参考的共同密度误差，不能把白化自带的相关信息误称为网络学到的新物理。
核沉积的周期/平移规则已检验；本次有限维凸网络没有结构化保证连续平移对称性，
外势相位留出只检验近似表现，不代替对称性证明。
源/目标均值和协方差使用配对分块新增误差检查，相关时间同时检查均值和协方差影响量。
当现有时间段容纳不了至少八个合适时间块时，保留拟合作为明确标记的经验原理试验，
不将其输出升级为噪声合格的生产训练标签。
训练由 GPU 作业执行；有 CUDA13 和 CUDA12.1 两个本地候选运行环境，
作业中检查实际 GPU 内核可运行后才开始，记录版本和设备，不退回 CPU 训练。
