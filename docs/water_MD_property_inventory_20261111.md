# 纯相水 MD 的补充分析完整清单

日期：2026 年 11 月 11 日。适用于当前讨论的固定温度、1 ns、约 2000 帧的纯相水轨迹。已有 g(r) 等结果；具体已完成项目和轨迹字段尚未逐项核查。本文列出建议覆盖的分析范围，不声称已执行，也不意味着每项都适合当前采样。

目的：为老师提出的局部邻居位置与取向表示提供输入、可解释的结构检验和可追溯统计，同时保留与经典密度泛函及多体关联的比较接口。

## 数据条件和执行级别

- A：有完整 O/H 坐标、每帧盒矩阵、分子映射与时间戳即可做静态统计；需先通过平衡、周期边界和样本数检查。
- B：现有时间序列可以探索，但约 0.5 ps 存帧会限制短时信息，结果须做时间窗、相关性和收敛分析。
- C：需额外字段、可调用的原力场或更密集存帧；当前坐标不能自动提供。
- D：需额外状态点、外场/扰动、自由能计算或明确训练目标；不能由当前单状态坐标直接给出。

“全补”优先做所有适用 A 项、再做有统计支持的 B 项。C/D 项登记缺少什么，补齐数据后再实施。高阶联合直方图必须控制维数；不得将空白统计区域插值成已经采样的证据。

## 共同前处理和统计合同

保留原始轨迹与已有结果。记录力场名称/版本、单位、温度、N/V/压力、系综、约束、积分步长、保存间隔、恒温/恒压器及阻尼、截断和长程处理。重建完整水分子，局部位移使用周期最小镜像；MSD 使用可靠的无跳跃坐标。三斜盒按盒矩阵处理。

每项输出应带：定义与符号、单位、分子/壳层筛选、距离和角度测度、归一化、截断、bin、样本数/占据数、时间块误差、平衡段选择、来源轨迹与帧、软件与参数。NPT 的 RDF 归一化需说明体积处理方式。OH/HH 的分子内与分子间贡献分开。体相实验室坐标中的整体取向应作为各向同性检查，不能替代分子相对取向。

### 2 取向和相对转角

以两根 OH 键、几何角平分线 u、分子平面法向 n 描述水分子。u 是几何取向，不能自动当作真实电偶极。平面法向在交换两个 H 时变号；统计与模型必须对相同 H 的置换保持物理一致。

| 编号 | 项目 | 条件及用途 |
|---|---|---|
| O01 | 角平分线、OH、分子平面在实验室系的取向分布 | A；各向同性及采样偏置检查 |
| O02 | 中心取向与中心到邻居方向的 P(r, u_i·Rhat_ij) | A；中心朝向哪里 |
| O03 | 邻居取向与邻居到中心方向的 P(r, u_j·(-Rhat_ij)) | A；邻居怎样朝向中心 |
| O04 | 分子角平分线夹角联合距离分布 P(r,u_i·u_j) | A；平行/反平行等局部取向 |
| O05 | OH 与 O–O 方向的角分布，按两根 OH 对称处理 | A；区分与氢键有关的具体方向 |
| O06 | 分子平面相对夹角、相对 O–O 的平面方向 | A；使用不依赖任意 H 标签的定义 |
| O07 | 完整分子参考系间相对旋转、绕连心线扭转角 | A；角平分线夹角不是完整相对姿态；处理水的对称等价旋转 |
| O08 | 按壳层/氢键与否分组的上述分布 | A；不把距离变化误判成取向变化 |
| O09 | 距离分辨的 Legendre 取向相关，低阶 l=1、2 起步 | A；报告使用的向量与归一化，不与时间相关混淆 |
| O10 | 中心分子坐标系中的邻居 O/H 三维空间分布 | A；得到可解释的水合结构图；相同 H 置换须对称化 |
| O11 | 固定距离下多个相对角的低维联合分布 | A；先二维切片再增维，记录空 bin 和有效样本 |

## 推荐的统一输出组织

每条轨迹单独生成结果和元数据，跨轨迹按状态点汇总；不覆盖现有文件。

- 环境数据：HDF5 或等效可分块格式，保存 frame/time/box/center_id/neighbor_id/relative_positions/OH_vectors，以及可用的能量/力标签。可变长邻居使用 offsets 或 mask，不用零距离充当真实邻居。
- 逐分子指标：表格式保存 q、配位、最近邻距离、氢键供受体数、LSI、Voronoi 体积及来源索引。
- 分布与相关：保存 bin edges、原始 counts、归一化值、块误差、有效区间，不能只有图片。
- 网络：保存定义过的氢键边及必要的环统计，不默认输出所有组合环。
- 采样报告：实际状态点、平衡段、分块、相关性、失败项及缺失字段。
- 学习划分：持久保存按轨迹、时间段、状态点划分的索引，所有描述符和标签共用同一划分。

## 怎样安排全量补充

第一批：共同前处理 + 适用 A 项；重点为 O、T、H、M 类，复用已有 RDF。C 类先检查字段是否已有，能由原模型重算的静态能量/力另作任务，不默认已有。

第二批：D01–D10 等慢时间尺度 B 项，加相关时间和置信区间。D11 及高维尾部仅在样本支持时继续。

第三批：按目标补高频短轨迹、速度/应力/偶极/极化率或额外状态点，再做相应 C/D 项。若当前研究重点是局部表示与泛函，光谱、黏度、热导率不应成为阻碍主线的前置要求。

- [waterdynamics 官方文档](https://www.mdanalysis.org/waterdynamics/)：取向弛豫、角分布、MSD 与驻留分析的工具范围，不证明本轨迹已收敛。
- [MDAnalysis MSD](https://docs.mdanalysis.org/stable/documentation_pages/analysis/msd.html)：明确 MSD 需要无跳跃坐标。
- [GROMACS dipoles](https://manual.gromacs.org/current/onlinehelp/gmx-dipoles.html)：总偶极涨落与介电分析需要电学数据及边界约定。
- [GROMACS energy](https://manual.gromacs.org/current/onlinehelp/gmx-energy.html)：能量及涨落分析要匹配系综和实际采样字段。
- [GROMACS 黏度相关说明](https://manual.gromacs.org/current/reference-manual/analysis/curve-fitting.html)：压力相关法有噪声尾部和收敛困难，不适合由稀疏坐标强行估计。

以上是项目用途下的分析清单，不存在有限的“所有可能高阶量”清单。保留逐分子原始环境是为将来新增统计而不丢失输入；是否完成全量任务，应按各项数据条件与实际统计支持判定，而非只看有没有输出文件。
